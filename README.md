# 🛡️ Lost From Light (LFL) // Cyber Defense & CTF Platform

> **100% İstemci Taraflı (Zero-Backend) Siber Savunma ve Kali Linux Terminal Simülasyon Platformu**  
> GitHub Pages üzerinde doğrudan çalışacak şekilde optimize edilmiştir.

---

## ⚡ Canlı Önizleme (GitHub Pages)
Bu proje saf HTML5, CSS3 ve Modern Vanilla JavaScript ile inşa edilmiştir. Herhangi bir harici sunucu, Node.js veya veritabanı kurulumuna ihtiyaç duymaz.

### 🚀 Nasıl Çalıştırılır?
* **GitHub Pages ile:** Deponun `Settings -> Pages` menüsünden `Branch: main / (root)` seçeneğini aktif etmeniz yeterlidir.
* **Yerel Olarak (Local):** `index.html` dosyasına çift tıklayarak doğrudan dilediğiniz tarayıcıda (Chrome, Edge, Firefox, Brave) açabilirsiniz.
* **VS Code / Live Server ile:** VS Code üzerinde `index.html`'e sağ tıklayıp *"Open with Live Server"* diyebilirsiniz.

## 🎯 Temel Özellikler
1. **🐉 Kali Linux Web Terminali (Multi-Tab CLI):**
   * Sekmeli terminal yapısı (`+` yeni sekme, kapatma, sekme başına bağımsız geçmiş).
   * Kütüphanedeki **142 Kali Linux komutunu** (Nmap, Gobuster, SQLMap, Volatility, Wireshark, Metasploit vb.) tanır ve simüle eder.
2. **🚩 6 Kademeli Siber CTF Arenası (Bayrak Avı):**
   * Seviye 1.1 (Ağ Keşfi) -> Seviye 3.2 (Grand SQL & Root Boss) kademeli sızma operasyonu.
   * **<kbd>Tab</kbd> Tuşu ile Otomatik Tamamlama (Auto-Complete):** Komutun başını yazıp Tab'a basıldığında komutu otomatik tamamlar.
   * Yerel hafıza (`localStorage`) sayesinde kazanılan XP'ler ve seviye ilerlemesi asla kaybolmaz.

4. **📱 %100 Responsive Mimari:**
   * Masaüstü, tablet ve mobil uyumlu esnek ızgaralar ve off-canvas çekmece navigasyon menüsü.
